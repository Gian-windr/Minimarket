# Proyecto Personal - MiniMarket Don Manuelito

### Sistema Elaborado con Java + Spring Boot + PostgreSQL + Thymeleaf

→ React y React Router Dom para el Frontend y Spring Boot para el Backend, con PostgreSQL como base de datos.

→ React se utiliza para construir la interfaz de usuario del proyecto, permitiendo una experiencia interactiva y dinámica para los usuarios.

→ React Router Dom se utiliza para gestionar la navegación entre diferentes páginas de la aplicación, proporcionando una experiencia de usuario fluida y sin recargas de página.

→ Spring Boot facilita la creación de servicios RESTful para manejar las solicitudes del frontend, permitiendo una comunicación eficiente entre el cliente y el servidor.

→ PostgreSQL se utiliza para almacenar y gestionar los datos de la aplicación, proporcionando una base de
datos robusta y escalable para el proyecto.

→ Thymeleaf se utiliza para renderizar las vistas del lado del servidor, permitiendo una integración sencilla con Spring Boot y facilitando la generación de contenido dinámico en las páginas web.

### Funcionalidades del Proyecto:
- Gestión de Productos: Permite agregar, editar y eliminar productos del inventario, así como visualizar la lista de productos disponibles.
- Gestión de Clientes: Permite agregar, editar y eliminar clientes, así como visualizar la lista de clientes registrados.
- Gestión de Ventas: Permite registrar ventas, generar facturas y visualizar el historial de  ventas realizadas.
- Gestión de Usuarios: Permite administrar los usuarios del sistema, asignar roles y controlar el acceso a diferentes funcionalidades según el rol del usuario.
- Reportes: Permite generar reportes de ventas, productos más vendidos, clientes frecuentes, entre otros, para facilitar la toma de decisiones y el análisis del negocio.
- Interfaz Intuitiva: La aplicación cuenta con una interfaz de usuario amigable e intuitiva, facilitando la navegación y el uso de las diferentes funcionalidades del sistema.
- Seguridad: Implementa medidas de seguridad para proteger los datos y garantizar el acceso autorizado a las funcionalidades del sistema, utilizando autenticación y autorización basada en roles.
- Integración con Base de Datos: Utiliza PostgreSQL para almacenar y gestionar los datos de la aplicación, asegurando la integridad y disponibilidad de la información.
- Escalabilidad: El proyecto está diseñado para ser escalable, permitiendo la adición de nuevas funcionalidades y la expansión del sistema a medida que el negocio crece, sin comprometer el rendimiento o la estabilidad de la aplicación.
